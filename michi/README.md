# 果てなき道（試作）

電気の止まった町と、入口からてっぺんまで自分の足で登れる電波塔。`index.html` をブラウザで開くだけで遊べます。

- 移動 WASD・矢印／走る Shift／調べる・使う E／押しのける F／休む Z／持ち物 1〜9（スマホは画面の左下を指でなぞる）
- 塔：止まった自動ドア → ロビー・チケット売り場・おみやげ売り場・展示室・スタッフ室 → 地下の機械室 → 非常階段（1段ずつ） → 展望台 → 点検階 → はしご → てっぺん
- 電気：ガソリンスタンドの携行缶 → 発電機に給油・始動 → ブレーカー → エレベーター・明かり・てっぺんの赤いランプ
- 民家とスタンドの店は中まで入れて、棚・冷蔵庫・たんすを調べられる

テスト：`node michi/tests/bot.js`（階段で展望台まで登る／電気を戻しててっぺんまで行く／描く速さ）、写真：`node michi/tests/shots.js`
