# 果てなき道

電気の止まった町を、ともだちと二人で歩く。建物はどれも中まで入れて、電波塔は入口からてっぺんまで自分の足で登れる。`index.html` をブラウザで開くだけで遊べます（スマホ可）。

## 操作
- 移動 WASD・矢印／走る Shift／調べる・使う E／押しのける F／休む Z／持ち物 1〜9／地図 M／写真 P
- スマホ：画面をなぞって歩く、右下のボタンで調べる・押す・休む
- 迷ったら少し立ち止まる。ともだちが次の行き先を指さして、その場所がきらっと光る（地図にも丸が出る）

## 町
- **電波塔**：止まった自動ドア → ロビー・チケット売り場・おみやげ売り場・展示室・スタッフ室 → 地下の機械室 → 1段ずつの非常階段（10階ぶん） → 展望台 → 点検階の柵 → はしご → てっぺん
- **電気**：ガソリンスタンドの携行缶 → 発電機に給油・ひもを引く → ブレーカー → 塔の明かりが下から順に灯る → エレベーター・広場の街灯・てっぺんの赤いランプ
- コンビニ、ガソリンスタンド、民家6軒（2階建て2軒）、3階建ての学校（教室・音楽室・屋上）、駅と止まった電車、神社の森、公園と池、川と橋
- 朝・昼・夕焼け・夜がめぐり、夜は懐中電灯と焚き火。布団で眠ると朝になる。30秒ごとに自動で保存

## 作り
- `src/*.js` を `node michi/build.js` でつないで `index.html` を作る（`src/shell.html` が外枠）
- 斜め見下ろしの Canvas2D。階ごとのマス目（地下1階〜11階）、壁は手描きのドット模様、屋根より上は近づくと透ける
- 音楽と環境音は WebAudio でその場で鳴らす（ピアノ・オルゴール・弦・風・川・ひぐらし・虫）
- 重い端末では、雲の影・光の筋・木の影などから自動で軽くする

## テスト
- `node michi/tests/bot.js`：どの建物のどの階にも歩いて行けるか／非常階段で展望台まで／鍵 → 地下 → 燃料 → 発電機 → ブレーカー → エレベーター → 柵 → はしご → てっぺん → 夜の望遠鏡／民家の2階・学校の屋上・電車／眠る・保存／ヒント／ゾンビ・歩きまわり・描く速さ
- `node michi/tests/look.js <保存先> street,deck,night,...`：場面ごとの写真
