# 果てなき道

だれもいない世界を、ともだちと二人で歩く。目に入った場所には、どこへでも歩いて行けて、建物はどれも中まで入れる。`index.html` をブラウザで開くだけで遊べます（スマホ可）。

## 遊び方（説明はこれだけ）
- 移動 WASD・矢印／走る Shift／調べる・使う E／押しのける F／休む Z／持ち物 1〜9／地図 M／写真 P
- 見回す：右ドラッグ（スマホは二本指）／遠く・近く：ホイール・＋−（スマホはピンチ）
- 場所の名前・時計・矢印・ヒントは出ません。時間は空の色と、町の時計で。地図は拾った紙の地図だけ（自分の居場所は書いていない）
- ともだちは道案内はしません。気づいたことを、ふつうに話すだけ

## 世界
- **はてのまち**：電波塔（ロビー〜地下の機械室〜10階ぶんの非常階段〜展望台〜点検階〜はしご〜てっぺん）、駅と止まった電車、学校、神社、公園、コンビニ、スタンド、民家
- **はて川**：車の橋と、線路の鉄橋（歩いて渡れる）
- **ひかりが丘ランド**（遊園地）：入口のアーチと回転ゲート、きっぷ売り場、観覧車（乗れる。てっぺんで見回せる）、メリーゴーランド（木馬に乗れる）、ジェットコースター（巻き上げ・重力で走る）、お化け屋敷（真っ暗な迷路と仕掛け）、スワンボート（池をこげる）、屋台村、噴水、花時計、レストラン、おみやげ屋、救護室、裏方の管理棟（電気室・控室）、駐車場
- **ひかりが丘**：小さな駅と村。夜、二階の窓に灯りがともる家がある
- **はまなす海岸と灯台岬**：寄せては返す波の砂浜、松林、らせん階段で灯室と外の回廊まで登れる灯台（夜は光が回る）

## 電気
- 塔：スタンドの携行缶 → 地下の発電機 → ブレーカー → 地下から順に明かりがつく → エレベーター
- 遊園地：きっぷ売り場の鍵 → 管理棟の門 → 作業台のスパナ → 駐車場の社用バンからバッテリー → 非常用発電機 → 主ブレーカー → 設備ごとのブレーカー（照明・観覧車・メリーゴーランド・コースター・お化け屋敷・噴水）→ それぞれの操作盤で〈運転〉。夜は電飾が灯り、スピーカーから音楽が流れる

## 空気
- 朝・昼・夕焼け・夜、ときどき雨（音も）、朝もや、川と波の音、虫・ひぐらし・鳥
- 望遠鏡は100円玉で1分。てっぺんや観覧車の上からは、自分の目で見回せる

## 作り
- `src/*.js` を `node michi/build.js` でつないで `index.html` を作る（`src/shell.html` が外枠）
- 斜め見下ろしの Canvas2D。階ごとのマス目、壁は手描きのドット模様、近づくと屋根や手前の壁が透ける
- 音楽と環境音は WebAudio でその場で鳴らす。重い端末では、雲の影・光の筋・木の影などから自動で軽くする

## テスト
- `node michi/tests/bot.js`：どの建物のどの階にも歩いて行けるか／塔の電気からてっぺん・望遠鏡まで／遊園地の電気から観覧車一周・木馬・コースター一周・スワンボート・お化け屋敷の迷路まで／灯台の灯室・灯りの家／眠る・保存・紙の地図／歩きまわり・描く速さ
- `node michi/tests/look.js <保存先> street,pgate,wheeltop,pnight,...`：場面ごとの写真
