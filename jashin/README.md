# 邪神の領域

毎回ちがう土地が生まれる、ゾンボイド式のサバイバル・アクション。`index.html` 一枚で動きます（ブラウザで開くだけ。スマホも可）。

- 職業：戦士・盗賊・魔女・僧侶（それぞれに技がある）
- 生き延びる：空腹・のどの渇き・眠気・出血・穢れ（100%で眷属になる）。昼と夜。物音で眷属が寄ってくる。扉を閉め、窓を板で塞ぐ。死んだら終わり。
- 目的：四つの邪神の祠を砕くと、中央の遺跡の門が開く。その奥の「邪神の化身」を倒す。

## 操作
- パソコン：WASDで移動（Shiftで走る・Cで忍び足）、マウスで向き、左クリックで攻撃、右クリック/Qで技、Spaceで押し返す、Eで調べる、Rでほかの行動、Tabで持ち物、Mで地図、Fで灯り、Hで手当て、Escで一時停止
- スマホ：左をなぞって移動、右下のボタン（攻撃・技・押す・調べる・走る）、「調べる」長押しでほかの行動

## テスト
```sh
# 自動で遊ぶボット（エラー・詰まり・難しさの確認）
node jashin/tests/bot.js [回数=3] [最大の日数=6] [不死身=0]
```
不死身（3つめを1）にすると、祠を砕いてボスを倒すまでの流れを通しで確かめられます。
