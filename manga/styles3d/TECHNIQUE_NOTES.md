# 劇画技法ノート（参考資料から抜き出した「技法」だけ）

ユーザーが見せてくれた参考資料（劇画・青年漫画の見開き約20枚）から、**一般的な技法だけ**を言葉にしたもの。
参考資料の画像そのもの・キャラクター・構図・デザインは使わない。描くものは毎回オリジナル。

## 1. 白と黒の配分
- **大きな余白 × 密度の高い主役**：画面の6〜7割を白（または単調な面）にし、主役だけを極端に描き込む。描き込みの差がそのまま視線誘導になる。
- **墨の飛沫・粉塵**：動きのある物の周りに、細かい黒点の飛沫（大小混ぜ、進行方向に流れる）。地面との接点にも散らす。
- **影は点描（ドット）で落とす**：白い地面に、点の密度で投影の影を描く。輪郭はぼかす。
- **黒地に白い線（スクラッチボード）**：夜空や闇は黒ベタに、白い細線で雲・渦・光を削り出す。渦は同心円の白線。

## 2. 空と雲
- 白い積雲：輪郭を短い平行ハッチで縁取り、内側は白く残す。背景の空は濃いクロスハッチか網点グラデ。
- 嵐の雲：流れの方向に沿った長いハッチを重ねる。
- 星空：黒〜濃グレーのグラデに、大小の白点。月は白抜き。

## 3. 質感の描き分け（線の種類）
| 素材 | 線 |
|---|---|
| 草地・荒野 | 短い「く」の字・点・短線を無数に。手前は大きく、奥は細かく密に。 |
| 瓦礫・土 | 不規則な多角形の塊を大小。影側に短いハッチ。 |
| コンクリートの廃墟 | タイル目地の格子＋ひび割れ＋露出した鉄筋＋欠けた縁。 |
| 生物の肉・ミミズ状の体 | **体の輪切り方向に沿った環状のハッチ**（等高線のように回り込む）。暗い面ほど密。 |
| 布・服 | 乾いた筆（ドライブラシ）でかすれた太い筆致。しわは筆の払い。 |
| 髪 | 根元から毛先へ流れる墨の筆線。毛先はばらけて細く、飛沫を少し。 |
| 金属・機械 | 均一で硬い線。パイプ・配線・パネル・ボルト。トーンは少なめ。 |
| 水しぶき | 弧を描く水の帯＋細かい粒の散布。 |

## 4. 光
- **リムライト（白い縁取り）**：暗い物体と暗い背景の境界に、白い細い縁を残して分離する。
- **白飛び（ブルーム）**：爆発・光源の周囲は描き込みを消して白で飛ばし、その外側から密度を戻す。

## 5. 動き
- **身体を包む曲線の流線**：打撃や斬撃は、体の周りを弧で包むスピード線（直線ではなく曲線）。
- 一点に収束する道路の流線：地面に消失点へ向かう太い放射線。
- 飛散物：破片・武具・土が軌跡を描いて飛ぶ。

## 6. 構図
- **巨大な空間 × 小さな人物**（スケール感）。
- **俯瞰の真上ショット**（地面の模様が主役になる）。
- **消失点1つの都市**：窓の格子が密に並ぶ高層ビル群が奥へ収束。
- **群衆・軍勢**：地平線まで並ぶ隊列を、手前は描き込み、奥へ行くほど記号化（点と縦線）。
- 対角線の構図：長い武器や体の線を画面の対角に置く。
- 左右に分けた対峙（真ん中に余白の帯）。

## 7. 数値の目安（1600px幅のコマ）
- ハッチの線間隔：明部 6〜10px、中間 3〜5px、暗部 2〜3px＋クロス。
- 主線：外形 2.5〜4px、内側 1〜1.5px。
- 黒の面積比：重いコマ 35〜55%、余白型のコマ 10〜20%（主役に集中）。
- 草・粉塵の短線：1コマあたり数千本（手前ほど大きく疎、奥ほど小さく密）。

## 8. 追加資料から（第2弾）
### 怪物・巨大生物
- 体全体を**グラデーショントーン＋白い霧**で包み、輪郭の一部を霧に溶かす（巨大さと奥行き）。
- 光る目は**白抜きの大きな面**で、周囲だけ暗くする。
- 爪・棘・脚を多数、リズムをつけて反復。手前は大きく鋭く、奥は小さく霧に沈める。
- 擬音は画面を横切る巨大な描き文字（黒＋白フチ、画面の端からはみ出す）。

### 荒れた線（グリッティ）
- 輪郭を一本で引かず、**短い引っかき線を重ねて**形を作る。ひび・傷・汚れを線で描き込む。
- 黒い衣服は黒ベタ＋白いしわのハイライト線。
- 千切れた布・肉片は、尖った不規則な破片の形。

### 混戦・破壊の構図
- 画面いっぱいに人物と破片を重ねる。手前の人物は画面からはみ出す。
- 斜めの太い流線が背景を埋め、その上に白い破片が飛ぶ。
- 真上・真下からの極端なカメラと、手前の大きな手（短縮法）。

### すっきりした美少女系の線（線の種類が全く違う絵柄）
- **主線は細く均一**、強弱は毛先や輪郭の端の「抜き」だけ。ハッチはほとんど使わない。
- **髪は束（房）で描く**：大きな房を数本、房の先を鋭く尖らせ、房の中に細い線を2〜3本。前髪は顔の上で房が重なる。
- **目は大きく、層で描く**：上まつげの太い線＋瞳の濃淡（上が濃く下が明るい）＋大小2つ以上の白いハイライト。
- 頬の赤みは**細い斜線3〜5本**。
- 影は少なく、首の下・髪の下にだけ1段階のトーン。

### 設定画の描き方（正面・斜め・横）
- 同じ人物を**正面／4分の3／横向き**で並べ、髪の房・髪飾り・服の特徴が全角度で一致するようにする。
- 表情差分（笑顔・目閉じ・口開き）を同じ顔の角度で並べる。

## 9. 人物の形（写真資料から）
写真はポーズ・体の量感・表情の「仕組み」だけを読む。写っている人物の顔・服装・誰と分かる特徴は描かない。

### 短縮法（手前の手・足）
- カメラへ突き出した手は**顔の2〜3倍の大きさ**。指は付け根より指先が大きく、指の間が開いて見える。手のひらの皺と指の関節の横線で奥行きを出す。
- 手前の手はピントの代わりに**線を太く・細部を多く**、奥の顔は線を細く。
- 煽りで蹴り出す脚：靴底が画面の大部分を占め、膝から上が急に細く小さくなる。

### 極端なカメラ
- **真下から**：顎の下・鼻の穴・手のひらが見える。背景のビルは消失点が上空の1点へ収束。
- **真上から**：頭頂と肩、膝を抱えた形がほぼ円に収まる。床に落ちる影が形を説明する。

### 動きのある全身
- 跳躍：膝を胸に引き寄せ、腕は左右非対称に広げる。体幹は弓なり。足裏が見える角度。
- 走り：上半身を前傾、前の腕と後ろの脚が対角にそろう。上着が体から離れて後ろへなびく。
- ダンス・回転：裾やスカートは**遠心力で円盤状**に広がり、ひだは中心から放射。髪も回転方向に流れる。
- ポーズは常に**重心線**（頭→支え足）を意識し、体のひねり（肩と腰の向きのずれ）を入れる。

### 布
- コートは重く、裾が大きな弧を描いて遅れてついてくる。ベルトでくびれ、腰から下に縦の大きなひだ。
- シャツ・パーカーは関節の内側に放射状のしわ、引っ張られる側は長い直線のしわ。

### 手
- 開いた手：指は扇状にばらけ、指ごとに曲がり具合が違う（全部まっすぐにしない）。
- 鉤爪のように曲げた手：第2・第3関節が角張り、指先が手のひら側へ巻く。
- 手首から指先までが1つの弧になるように。

### 表情の解剖
- **叫び・恐怖**：口が縦長に大きく開き、上下の歯と舌が見える。眉間に縦じわ、目を見開く（白目が上下に見える）か、ぎゅっと閉じて目尻に放射状のしわ。鼻の横から口角へ深いほうれい線。首の筋が浮く。
- **泣き叫び**：眉の内側が上がり、目は閉じて押しつぶされ、頬が持ち上がる。涙の筋は細い線＋ハイライト。
- **無表情・静けさ**：眉は水平、口は閉じて口角は動かない。描き込みを減らし、目の光だけを残す。
- しわは**線の数ではなく位置**で効く：眉間・目尻・ほうれい線・額の横じわの4か所。

## 0. 大原則（全体のバランス）
- 特定の構図・絵柄・カメラ（例：真上からの俯瞰）に寄せない。**すべての絵柄・構図・ジャンルを底上げする**。
- 「ユーザーが気に入った」は伸ばす価値の目安であって、既定値にはしない。ランダム生成と編集者の判断の幅を狭めないこと。
- 評価は毎回、ゆるかわ／劇画／すっきり線／ギャグ／ホラー／絵本など**複数の絵柄 × 複数のカメラ**で並べて行い、どれか一つだけが良くなっていないかを確かめる。
