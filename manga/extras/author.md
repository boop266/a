# 『うちの物干しに雲がいる』 裏話と設定資料

> この資料について
> - 「裏設定」とあるところは、本編を描き終えてから作者が考えたものです。本編の絵やセリフとはぶつからないようにしてあります。
> - 「制作の記録」とあるところは、実際の原稿と編集チェック（第1回〜第3回）で起きたことだけを書いています。

---

## 1. キャラクター設定資料

### ハル
- **プロフィール**：小学2年生、7さい。お母さんと二人で、物干しのある庭つきの家に住んでいる。
- **本編に出ない過去・秘密（裏設定）**
  - 去年、自分も遊園地で迷子になったことがある。
  - 迷子のこわさを知っているので、灰色で泣いているモクを見て、ほうっておけなかった。
  - 本編の「まいごなんだ…」（p5）は、そのときを思い出した顔、というつもりで描いている。
- **口ぐせ**：「そうだ！」。思いついたら、考えるより先に口に出る（p11）。
- **好きなもの**：にらめっこ、ボタン集め（髪どめのボタンは、いちばんのお気に入り）。
- **苦手なもの**：かみなりの音。モクが大きな雨雲にならなくて、ほっとしている。
- **デザインの意図**
  - 白黒の画面で、遠くからでも一目で分かるように、黒いおかっぱ・顔の付いたボタンの髪どめ・水玉のシャツの3つを目印にしている。
  - **制作の記録**：第1稿では、シャツはしましま（ボーダー）だった。第1回の編集チェックで「おかっぱと前髪にボーダーのシャツだと、有名な作品の少女キャラと雰囲気が少し近い」と言われた。編集者の判断は「問題ない範囲」で、直すかどうかは任意だったが、念のため水玉に変えた。
  - 髪どめを星形にする案も考えたが、ありふれた形なのでやめて、ボタンにした。

### お母さん
- **プロフィール**：30代なかば。家のことを一人で切り盛りしている。晴れた日曜に洗濯物を全部干すのが、何よりの楽しみ。
- **本編に出ない過去・秘密（裏設定）**
  - 子どものころ、近所のにらめっこ大会で負けたことがない「変顔の名人」だった。
  - 大人になってからは封印していて、ハルの前でも見せたことがなかった。
  - p13 の「お母さんの本気」は、何十年ぶりかの封印解除。ハルが驚いているのは、変顔そのものより「お母さんがこんな顔をできたなんて」の方が大きい。
- **口ぐせ**：「〜わよ」「〜わねぇ」。「あんた、便利ねぇ」（p8）のように、思ったことがそのまま口に出る。
- **好きなもの**：快晴、布団たたきで布団を叩く音、取り込んだ洗濯物のにおい。
- **苦手なもの**：急な雨（物語の最初の日に、ちょうどこれが起きる）。
- **デザインの意図**
  - 髪をトーン（網点）にしたのは、白黒の画面でハルの黒髪と並んだとき、髪の色だけで見分けられるようにするため。
  - おだんご頭・白いエプロン・黒い長いスカートで、全身のシルエットもハルと違う形にしている。
  - **制作の記録**：第1稿では、お母さんの目に「まつげのある目」と「まつげのない目」が混ざっていた。第1回の編集チェック（任意1）で、まつげのない目にそろえた。
  - **制作の記録**：お母さんの持ち物は、第1稿ではほうきのつもりだった。でも細い棒の先の形が分かりにくく、第1回の編集チェック（推奨1）で「何を振り回しているのか分からない」と言われた。そこで、うずまき形の頭の布団たたきに変えた。

### モク
- **プロフィール**：ちいさな雨雲の子ども。生まれてまだ一年たっていない（雲として）。
- **本編に出ない過去・秘密（裏設定）**
  - 家族の中でいちばん小さく、まだ自分の力で高い空まで昇れない。ふだんはお父さん雲の後ろにくっついて旅をしている。
  - あの日は、強い風で手を離してしまった。
  - 物干しに降りたのは、白いシャツが雲の仲間に見えたから。
- **口ぐせ**：「えへへ」。照れると、すぐこれ。
- **好きなもの**：笑うこと、くすぐられること（p7）、花に水をあげること（p8）。
- **苦手なもの**：ひとりぼっち、強い風。
- **デザインの意図**
  - 色で気持ちを表すキャラクターにした。悲しいとトーンの灰色になって雨を降らせ、笑うと白くなってふくらむ。文字を読まなくても、雲の色だけで今の気持ちが分かる。
  - 編集チェックでも、第1回から「残すべき良い点」として挙げてもらえた。
  - 手足はなく、表情は目・眉・口だけで出している。

### 雲のパパ・ママ
- **プロフィール**：モクの両親。旅する大きな白い雲。
- **本編に出ない過去・秘密（裏設定）**
  - パパは若いころ、夕立を降らせる大きな雨雲だった。いまは落ち着いて、日陰を作る役目が気に入っている。
  - ママはパパよりよく笑う。だからいつもふわふわで、パパより少し高いところを飛んでいる。
- **口ぐせ**：パパは「うむ」、ママは「あらあら」（本編では「モクー」「どこー？」「モク！」しか言っていない）。
- **好きなもの**：パパは夕焼けの空、ママは虹。
- **苦手なもの**：二人とも、子どもとはぐれること。
- **デザインの意図**
  - モクと同じ雲の形のまま、パパは太い眉とひげ、ママはまつげで見分けがつくようにした。
  - **制作の記録**：第1稿の p9 では、空を流れていく雲を、顔のない灰色の雲で描いていた。第1回の編集チェック（推奨6）で「それがモクの家族だと分からない」と言われ、p11 の家族と同じ顔にそろえた。

## 2. 世界観の裏設定（作者が後から考えたもの）
- **雲の家族はどこへ旅しているのか**：季節ごとに、雨の足りない土地を回っている。春は田んぼ、夏は花だん、秋は果樹園。モクの家族は「町の花だん係」。本編のエピローグ（p16）で花だんにだけ雨を降らせているのは、その仕事。
- **雲が泣くと雨になるのはなぜか**：雲の体は水のつぶでできている。悲しいと、つぶが重く集まって落ちてくる。灰色に見えるのは、つぶがぎゅっと詰まっているから。
- **笑うとふくらむのはなぜか**：笑うと体の中に空気がたくさん入り、つぶの間が広がる。白く軽くなって、上へ昇っていく。本編の「ぷくっ」（p7）と「ぷくーっ」（p14）は、この仕組みを絵にしたもの。
- **うれし泣きの雨と虹**：うれしくて泣いた雨にだけ、日の光がよく通る。だから、うれし泣きのあとには虹が出る（p15 の大ゴマ）。
- **それからのモク**：ときどき家族と町の上を通りかかり、ハルの家の花だんに水をやっていく。お母さんとの約束で、洗濯物には降らない。

## 3. 作者あとがき

### 着想のきっかけ
洗濯物を干すと雨が降る。誰にでもある、ちょっと腹の立つ出来事を、「犯人がいたら？」とひっくり返したのが始まりです。犯人が小さな雲の子どもで、しかも迷子で泣いているだけだったら、怒っていたお母さんはどうするだろう。そこから話が動き出しました。

白黒の漫画なので、色の代わりに網点（トーン）を使っています。「悲しいと灰色、うれしいと白」というルールは、最初から絵で伝えたいと決めていました。

### 苦労したコマ
- **p13 のお母さんの変顔（大ゴマ）**
  - 第1稿では、頬に当てた手と肩をそのまま結んで描いたせいで、腕が丸太のように巨大になり、胴とつながって見えませんでした。編集チェックでは「山場が絵の崩れに見える」と言われました。
  - 第2稿では、ひじを顔の横で曲げる形に作り直しました。顔も「ウインクと舌出し」から、寄り目・広がった鼻の穴・舌出しにして、ハルの「あっぷっぷ」よりはっきり崩れた顔にしました。
- **p4 の布団たたき**
  - ほうきから布団たたきに変えたところ、今度は「待って！」のコマで、うずまきの頭がハルの足の後ろに重なりました。ハルがフラフープの中に立っているように見えてしまったのです（第2回の必須A）。
  - 最後は、このコマだけ布団たたきを描かず、両手を上げて止まったお母さんにしました。代わりに「こらーっ！」のコマで、布団たたきの全体を一度しっかり見せています。
- **クライマックスの理屈**
  - 第1稿では、空の家族がモクのすぐ上にいたので、「どうして届かないの？」が伝わりませんでした。「笑うとふくらむ」も、ハルがいきなり言い出していました。
  - 第1回の編集チェックで指摘を受け、次の3つを足しました。
    - p7：くすぐって「ぷくっ」とふくらむ前振り
    - p11：家族を空高くに小さく描いた縦長のコマ（点線の矢印つき）
    - p14：「ぷく→ぷくぷく→ぷくーっ」と大きくなる、まるごと1ページ
  - p14 を足したことで、全15ページだった原稿が全16ページになりました。

### お気に入りのシーン
- **p13 の上の段**：後ろ姿の「笑いが足りないのよ」から、アップの「お母さんの本気、見せてあげる」へ続くところ。最初にほうきを振り回して雲を追い払っていたお母さんが、最後は同じ雲のために本気を出す。その切り替わりが、いちばん描きたかったところです。
- **p14 の上の段**：右から左へ、読む順に合わせてモクが大きくなる3コマ。漫画を読む向きそのものを演出に使えたのは、うれしい発見でした。
- **p8「あんた、便利ねぇ」「お母さん…」**：お母さんの性格が一言で出る、作者もくすっとしたやりとりです。

## 4. 没ネタ・幻のシーン
- **ハルの「ヘンなおどり」で晴れにするコマ（第1稿 p7）**
  - 第1稿の p7 の下の段は、次の3つのミニコマでした。
    - こちょこちょ
    - ハルのくねくねおどり
    - ポカポカの洗濯物
  - 第1回の編集チェックで「小さいコマの効果音が、黒いシミのように見える」と言われ、下の段を2コマに組み直しました。このとき、おどりのコマを外して、モクが「ぷくっ」とふくらむ前振りのコマに差し替えています。
  - おどり自体は、p12 の「くねくね」（笑わせようとして空回りする場面）に役目を移しました。
- **お風呂の湯気でモクを持ち上げる案（ネームの段階で没）**
  - 話を考えた最初のころは、「温かい空気は上に昇る」から、お母さんがお風呂をわかして湯気でモクを押し上げる、という解決も考えていました。
  - でも、それでは理科の実験になってしまいます。「笑うと晴れる」というこの話のルールとも、つながりません。それで「お母さんの変顔で笑わせる」に決めました。
