## 1. 編集後記

### 第1稿を読んだときの第一印象
第1稿は15ページでした。最初に感じたのは「骨組みがいい」ということです。

- **雲の色が気持ちを表すルール**：灰色の雲は泣いて雨を降らせ、白い雲は笑って晴れにする。このルールが、文字を読まなくても絵だけで伝わりました。第1回の記録にも「この作品の一番の発明」と書いています。
- **お母さんの一本筋**：最初は布団たたき（第1稿ではほうきのような棒）で雲を追い払おうとします。それが「あんた、便利ねぇ」と雲を使いこなすようになり、最後は「本気」を見せる。お母さんの変わり方に筋が通っていました。

その一方で、読者が止まってしまう所もはっきりしていました。第1回では、必須9件・推奨14件・任意5件を返しています。大きく分けると次の3つです。

- **クライマックスの理屈**：なぜ膨らむのか、なぜ届かないのか。
- **見せ場の絵**：p13 の変顔のコマで、腕が巨大で胴とつながっていなかった。
- **文字**：表紙の「雲」が黒いかたまりに見えた。効果音の「ー」が太い棒に見えた。

### いちばん大きかった直し
**「笑うとふくらむ」の前振りと、ふくらむ瞬間を描くこと**です（第1回の必須5）。

第1稿では、ハルが急に「うんと笑えばふくらむよ！」と言い出します。それまでに描かれていたのは「笑うと晴れる（白くなる）」ことだけでした。大笑いのすぐ次のページでは、モクがもう大きくなって飛んでいます。理屈の前振りと、いちばん気持ちいい「ぷくーっ」の両方が抜けていました。

これを最重要にした理由は、ここがお話の芯だからです。雲が高く飛べるようになる理由が分からないと、お母さんの見せ場も「なんとなく解決した」で終わってしまいます。

作者はこう直しました。
- **前振り**：p7 の、くすぐって笑うコマで、モクを少しふくらませた。効果音は「ぷくっ」、ハルのセリフは「ふくらんだ？」。
- **ふくらむ瞬間**：p14 を1枚丸ごと足した。上の段の3コマで「ぷく」→「ぷくぷく」→「ぷくーっ」と大きくなり、下の大ゴマで物干しから浮き上がる。これで全16ページになりました。

同じくらい大事だったのが、**家族との距離**です（第1回の必須4）。第1稿の p11 では、家族の雲がモクのすぐ真上にいました。それなのに「どこー？」「とどかない…」と言っています。

作者はここを縦長のコマに描き直しました。家族を空の高いところに小さく置き、あいだを点線の矢印と鳥で埋めています。これで「届かない」が絵だけで分かるようになりました。

### 3往復で、作品がどう良くなったか
- **第1回（第1稿・15ページ）**
  - 必須は9件です。中心は、理屈の前振り（必須4・5・6）、p13 の見せ場の絵（必須8）、読む順番（必須7）、文字のつぶれ（必須1・2・3）でした。
- **第2回（第2稿・16ページ）**
  - 必須9件のうち8件が直りました。
  - p13 の変顔は、寄り目・鼻の穴・舌を出した顔になりました。見ているハルも大きく描かれ、本当に「本気」の顔になっています。
  - 推奨にした「お母さんの『高く、ねぇ…』が回収されていない」点も直りました。後ろ姿の「笑いが足りないのよ」でつないであり、見せ場への入り方が一段良くなっています。
  - ただし、p4 の「待って！」のコマ（記録では p4-5）で、新しい崩れが出ていました。布団たたきのうずまきの頭がハルの足の後ろに重なり、輪の中に立っているように見えたのです。これが必須1件として残りました。
  - p14 の大ゴマと p15-1 がほぼ同じ構図になっていたので、これも推奨で返しています。
- **第3回（第3稿）**
  - p4 の「待って！」のコマは布団たたきを描かず、両手を上げて止まったお母さんにしました。
  - p15-1 は下からあおぐ構図にし、点線の矢印を入れて描き直しました。
  - 必須はゼロになりました。残ったのは、好みの範囲の任意2件です。p15-1 のしっぽの先と、PC 画面でビューアーの説明文が少し切れる件です。

まとめると、絵と文字の仕上げは毎回着実に良くなりました。いちばん効いたのは、「なぜそうなるか」を絵の中に前もって置いていった直しです。

### 「完成」と判断した決め手
- 山場が「理屈で納得できて、絵で笑える」形になったこと。前振り（p7）、距離（p11）、ふくらむ瞬間（p14）、届いた（p15）が一本の線でつながりました。
- 直したことで新しく崩れた所が、第3稿では見当たらなかったこと。
- 残すべきだと最初に挙げた所が、3回の直しを経ても全部残っていたこと。雲の色のルール、「便利ねぇ」、うれし泣きの虹、1ページ目と重なる終わり方です。

## 2. 伏線の解説

| 伏線（どこで） | 回収（どこへ） | ひとこと |
|---|---|---|
| p2-1 ナレーション「日曜日。朝からいい天気。」と、お母さんの「洗濯日和ね！」 | p16-1「今日もいい天気！」 | 1ページ目（本編の最初）と最後のページが重なる、円を描くような終わり方 |
| p3-4「うちの洗濯物だけ…」「ピンポイントだね」 | p16-4「洗濯物には降らないでよー！」「はーい」 | 洗濯物にだけ雨を降らせる困った雲が、言うことを聞く家族ぐるみの友だちになる |
| p4-5「ぽろぽろ」：泣くと雨になる | p15-3 の虹「うれし泣きかしらね」 | 同じ「泣く＝雨」のルールを、悲しい雨からうれしい雨へひっくり返している |
| p5-2「風がはやくて／みんなにおいてかれた」 | p9-2 頭の上を流れていく家族の雲 → p11 の再会 | p9 の雲は、p11 と同じ顔（ヒゲのお父さん雲・お母さん雲）。第2稿でそろえた所 |
| p6-3 ハルの「あっぷっぷ」、p6-4 モクの「ぷふっ」で白くなる | p7-1「笑うと晴れるんだ！」 | 雲の色のルール（灰色＝悲しい／白＝うれしい）が、ここで言葉になる |
| p7-5「ぷくっ」「ふくらんだ？」 | p11-5「うんと笑えばふくらむよ！」→ p14「ぷく→ぷくぷく→ぷくーっ」 | 第1回の必須5で足した前振り。クライマックスの理屈の土台 |
| p7-3 お母さん「その子を笑わせ続けて！」 | p13 お母さん自身の変顔 | 人に頼んでいたことを、最後は自分でやる |
| p6-3・p12-1 ハルの同じ「あっぷっぷ」 | p13-3 お母さんの「べろべろばあ〜っ！」 | 同じにらめっこが、ハルでは効かず、お母さんの本気で決まる。だから変顔をハルより一段上の顔にした（第1回の必須8） |
| p8-1「お花がしおれてる」、p8-3 モクが水をまく「サァァ…」 | p16-2 花に降る「サァ…」と p16-3 ハルの「あっ！」 | 去ったはずのモクが戻ってきたことを、姿より先に雨で見せている |
| p8「あんた、便利ねぇ」 | p16-4「洗濯物には降らないでよー！」 | お母さんの、ちゃっかりした性格が最後まで変わらない |
| p10「でもぼく小さいから／高くとべないの」、お母さんの考えごと「高く、ねぇ…」 | p13-1「笑いが足りないのよ」→ p13-2「お母さんの本気、見せてあげる」 | 第2回で、宙に浮いていた考えごとをここにつないだ |
| p11-1 の点線の矢印（地面から家族まで。届かない） | p15-1 の点線の矢印（地面からモクまで。届いた） | 同じ記号で、「届かない」と「届いた」が対になっている。第3稿で p15-1 を描き直したときに入った |

作り方の小さな工夫も一つ。p14 上の段の3コマは、右から左へ読む順に、モクが小さい→大きいと並んでいます。漫画を読む向きが、そのまま「ふくらんでいく時間」になっています。

## 3. 続編につながるヒント

ここからは、本編に描かれていることをもとにした**編集者の思いつき**です。作者が決めた裏設定ではありません。

- **モクの一家が遊びに来る**：p16 では、家族ぐるみでハルの家に来ています。「お父さん雲は大きいから、降らせる雨の量もけた違い」など、家族の一人ひとりで一話が作れそうです。
- **お母さんとの約束「洗濯物には降らないで」**：守れるか守れないか。それだけで、次の騒ぎの種になります。
- **泣くと雨、笑うと晴れ、笑うとふくらむ**：このルールは、まだ「怒ると？」「くしゃみをすると？」などに広げられます。新しい気持ちと新しい天気を一つずつ足していく作り方が、この作品には合っていると思います。
- **ハルの髪どめ**：顔の付いたボタンの髪どめは、第2回でハルの目印として残した所です。本編では何の意味も持たせていません。続編で使うかどうかは作者しだいです。
