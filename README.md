# 八つ枠のカバン

持ち帰り型のローグライク。`index.html` 一枚で動きます（ブラウザで開くだけ）。

## テスト

Playwright（Chromium）で動かします。

```sh
# 見つかったバグを一つずつ狙って再現する回帰テスト
node tests/regress.js

# 自動で遊び続けて、JSエラーと操作不能を探すボット
node tests/bot.js [回数=4] [1回あたりの手数=600] [幅x高さ=390x844]
```

ボットの環境変数:

| 変数 | 意味 |
|---|---|
| `START=49` | その階（0始まり）から潜る |
| `GOD=1` | 倒れないようにして奥まで見る |
| `QS=zone=ship` | テスト用URLパラメータ（`zone=grave` `zone=nest` `zone=pond` `ship=1` `blight=2` など） |
| `BOT_OUT=dir` | 操作不能のスクショの保存先（既定は `tests/out`） |

ボットはテストのときだけ、ゲーム内で `catch(e){}` に握りつぶされている例外も記録します。

# 夜鳴村（よなきむら）

`yonaki/index.html` 一枚で動く、ふたり協力のホラー脱出ゲーム。毎回ちがう村がランダムに生まれ、午前4時（4度目のサイレン）までに村から逃げ出します。

- **視界ジャック**：［視界］を長押しして見回すと、その方向にいる還り人（敵）や相棒の目を盗み見られる。覗いている間は動けない
- **還り人**：畑を耕す・見回る・墓に祈る・家の中に立つ、と生前の日課を続けている。明かり・足音・目の前の動きで気づき、追いかけてくる。倒しても、サイレンが鳴ると起き上がる
- **脱出条件**（毎回どれか一つ）：車で出る（鍵とガソリン）／鉄門を開ける（離れた巻き上げ機ふたつを同時に）／隧道の鎖を切る（ボルトカッター）
- **ふたりで**：［部屋をつくる］で出た4文字の合言葉を相棒が入力するとつながる（PeerJS）。倒れた相棒は40秒以内なら起こせる。間に合わないと還り人になり、自分と同じ顔で相棒を追う。還り人になった側は、視界ジャックで相棒を案内したり［物音］で敵をそらしたりできる
- **村の仕掛け**：先客のいる押し入れ、近づくと鳴り出して還り人を呼ぶ黒電話、背後で聞こえる鼻歌、近づくと消える障子の人影。どれも毎回ちがう場所にある
- **重い端末**では、最初の数秒で自動的に影と草を切って軽くする
- **顔写真**：タイトルの［顔写真］で選んだ写真が自分の顔になる（端末に保存され、相棒にも送られる）

three.js と PeerJS は CDN（cdn.jsdelivr.net）から読み込みます。

## テスト

```sh
node tests/yonaki.js            # 全部
node tests/yonaki.js ふたり      # 名前の一部で絞る
```

ネットのない環境では、`npm i three@0.160.0 peerjs@1.5.4` したフォルダの `node_modules` を `YNK_MODULES=/path/to/node_modules` で渡すと、CDN の代わりにそこから読みます。
テスト用URLパラメータ：`?solo=1` `?net=local&room=XX&role=host|join&autostart=1`（同じブラウザの別タブ同士でつながる） `seed=数字` `obj=car|gate|tunnel` `st=秒`（サイレンの間隔） `god=1` `bot=1` `fast=1` `mute=1`
