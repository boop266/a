# 黄泉還（よみがえり） — 設計

初代バイオハザードのような「洋館サバイバルホラー」を、1本のゲームとして作る。

## 芯（調べて確かめたことから）
- **緊張と緩和**（三上真司氏「ゲームの本質は『緊張と緩和』」Yahoo!ニュース特集）
  → 危ない廊下と、音楽が変わるセーブ部屋。扉の向こうが分からない間。
- **1発では死なないゾンビ**（同上「バイオは1発撃ってもゾンビは死なない」）
  → 弾は足りない。撃つか、避けて走り抜けるか（リスクとリターン）。
- **洋館を歩き回る楽しさ**（三上氏：洋風建築が好きで、おしゃれな洋館を歩くこと自体を楽しみとして出したかった）
  → 明治の洋館。部屋ごとに違う手ざわり。調べれば必ず一言返ってくる。
- **倒せる怪物の爽快感**（スウィートホームの「逃げるだけ」への疑問から、倒せる要素を入れた）
- **音**（廊下の犬の場面は「音」の使い方が怖さの元／環境音で空間を作る：電ファミ）
- **見えない先**（固定カメラで曲がり角の先が見えない＝遊んだ人・記事の声。三上氏本人は技術の制約からの選択と語っていたので「芯」とは呼ばない）
- **操作の不満**（「ラジコン操作めんどくさい」が一番多い不満）→ 初期は「かんたん操作」（倒した方向に進む）。ラジコン操作は設定で選べる。

## 1本のゲームとしての流れ
タイトル → オープニング（前庭・雨・犬）→ 洋館1F → 2F → 1F東 → 温室（中ボス）→ 地下 → 研究所 → 最深部（ボス1）→ 自爆まで3分 → ヘリポート（ボス2）→ エンディング（2種）→ 成績 → タイトル
- 死ぬと「YOU DIED」→ 最後にセーブした所から／タイトルへ
- セーブはタイプライター＋インクリボン（数に限り）。セーブ部屋にはアイテムボックス（どの部屋のボックスも中身は共通）。
- セーブ部屋は4つ：使用人部屋（1階）・書生部屋（2階）・管理人室（地下）・警備室（研究所）。どの階にも一つずつ、音楽が変わる安全な部屋がある。

## 物語（オリジナル）
明治の洋館「鷲尾邸」。三代当主・鷲尾弦一郎男爵は、病で亡くした娘・小夜（さよ）を取り戻すため、神代製薬に館の地下を明け渡した。研究は「黄泉計画」。七十年後、館の地下で事故が起きる。
県警・第七特殊対応班の如月遼（主人公）と早瀬は、消息を絶った先発隊を探しに鷲尾山へ。犬に襲われ、館へ逃げ込む。
- 早瀬：最初に館の奥へ消える。研究所の隔離房で、噛まれて熱にうかされている。血清を作って打てば、生きる（よい結末）。言葉は少なく、行動で存在を示す。
- 春日：ヘリのパイロット。合図があれば戻ると言って空へ。

## 部屋（全26＋前庭）と順路
（2階の書生部屋は、通しボットで「2階で持ち物があふれる」と分かって足した部屋）
1. 玄関ホール → 食堂（止まった大時計）→ 1F西廊下（最初のゾンビ・先発隊三浦の遺体）→ 使用人部屋（セーブ1・1Fの地図）→ 厨房（オーブンの中の真鍮の歯車）→ 食堂の大時計に歯車 → 鷹の鍵（時計が鳴り、ホールに何かが来る）
2. 2F西廊下（窓）→ 書生部屋（セーブ2・2Fの部屋）→ 子ども部屋（小さな鍵・小夜の絵日記＝名前）→ 寝室（鷹）→ 鏡台の引き出し（小さな鍵）→ 蛇の鍵（衣装棚からゾンビ）→ 2F西廊下の窓を破って犬
3. 2F回廊（蛇）→ 図書室（家系図・2Fの地図・押せる本棚の奥に狩猟用の鍵）→ 回廊の肖像画を生まれた順に → 狼の鍵
4. 1F東廊下 → 書斎（鷹）→ 銃の棚（狩猟用の鍵）→ ショットガン（東廊下にゾンビが来る）
5. 温室（狼）→ 庭師（中ボス）→ 地下室の鍵
6. 厨房 → 地下貯蔵庫（大蜘蛛・毒・青ハーブ・バルブハンドル）→ ボイラー室 → 管理人室（セーブ3）→ ボイラーのバルブを閉める → 地下通路 → 昇降機
7. 警備室（セーブ4・研究所の地図）→ 研究所廊下 → 研究室（試薬B・合成機）→ 培養室（狩人が割れて出る・IDカード・試薬A）→ 隔離房（ID・マグナム・早瀬）→［血清を作って早瀬に］→ 最深部（ID＋合言葉 SAYO）→ 救難信号 → ボス1 → 自爆3分 → 搬出路 → ヘリポート → ボス2（ヘリからグレネード）→ 脱出

## 完成の基準（これだけ作れば完成）
- 上の順路を、タイトルからエンディングまで、ボットが実際の操作ルール（当たり判定・鍵・敵）で通しきれる
- 全部の部屋・全部のカメラを写真で見て、おかしな所がない
- 死ぬ・続きから・セーブ/ロード・2つの結末・成績・タイトルに戻る、がすべて動く
- スマホ（横・縦）とPC（キーボード・ゲームパッド）で操作できる

## 遊びの決まり（通しボットと写真で見つけて、直したこと）
- **調べるボタン**：届く物のうち、まっすぐ向いている物が選ばれる。ほぼ同じ向きなら「拾う物 → 調べる所 → 扉」の順（時計の中に出た鍵は時計より先）。壁や家具の説明は、ほかに何もないときだけ。
  （前は「拾う物が必ず先」だったので、タイプライターの横にリボンがあると、持ち物がいっぱいのとき記録できなかった）
- **持ち物がいっぱいで拾えないとき**：もう使わない鍵があれば「捨てて拾う」かを聞く。武器なら「手に持っている武器をここに置いて、持ちかえる」かを聞く（置いた武器は床に残り、また拾える）。
  引き返せない屋上で、ヘリから投げ落とされたグレネードランチャーを拾えなくなることがない。
- **鍵の使い終わり**：IDカードは、隔離房の扉と合言葉の端末の両方で使い終わり。搬出路（引き返せない所）まで来たら、どの鍵ももう使わない。使い終わった鍵は、その場で捨てるか聞く。
- **敵の出てくる所**：家具や壁に体が食いこまない所に置く。隠れている敵（衣装棚・培養槽・水槽）は、現れる所（revealAt）を必ず決め、出来事もその場所を使う。椅子に座っていた敵などは、立ち上がったら近くの立てる所へ歩み出る。
- **ボスの突進**：突進の前に、立ち止まって身構え、吠える（0.5秒。体力が半分を切ると速くなり、約0.35秒）。見てから横へよければかわせる。撃ってひるませれば止まる。
- **研究所の弾**：マグナムは、警備員が一発だけ使った残りの5発が込めてある。隔離房の早瀬が、自分の弾倉（ハンドガンの弾15）を置いていく。
- **屋上の標識灯**：四隅に置くと四隅のカメラと一直線に並び、画面の真ん中をふさぐので、各辺の中ほどと昇降機の小屋の屋根に置く。

## 確かめ方（作ったあとに必ず通す）
- `node yomi/tests/bot.js [写真の保存先]`：通しプレイ。プレイヤーと同じ操作（スティックとボタン）だけで、タイトル→オープニング→洋館→地下→研究所→ボス2体→結末→成績→タイトルまで遊ぶ。途中でわざと一度死んで「最後に記録した所から」続ける。研究所の手前で記録2にも残し、後半は「つづきから」記録2を読んで、血清を打たないもう一つの結末まで遊ぶ。最後に、脱出の残り時間が0になると死ぬことも確かめる。
- `node yomi/tests/camcover.js`：全部の部屋で、歩いて行けるどの場所に立っても、ゲームが選ぶカメラに主人公が映るか（画面の外・壁の陰にならないか）。
- `node yomi/tests/touch.js`：全部の部屋の、拾う物・調べる所・扉について、その前に立って向いたとき、調べるボタンで「その物」が選ばれるか（タイプライターの横のリボンに取られて記録できない、のような取り違えを見つける）。
- `node yomi/tests/spawn.js`：全部の敵の出てくる所・現れる所が、立てる所にあるか（家具や壁に体が食いこんで動けなくならないか。ボス1が水槽の当たりに食いこんで歩けなかった不具合から足した）。
- `node yomi/tests/camsee.js <保存先>`：カメラごとに「映る範囲」を真上から描いた図。
- `node yomi/tests/cams.js <保存先>`：全部の部屋・全部のカメラの写真。
- `node yomi/tests/lighttune.js`：部屋ごとの画面の明るさ（暗すぎる所を見つける）。

## カメラの決まり
- 受け持ち（z/zs/lv）は「この場所はこのカメラで見せたい」という希望。カメラは、主人公が映るか（胴が画面の内にあり、壁や家具に隠れていない）を確かめてから選ぶ。今のカメラが受け持ちの中で映せていれば、切り替えない。
- カメラは自分の真下や手前を映せないので、受け持ちは「カメラから見て奥のほう」にする。
