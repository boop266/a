# 黄泉還（よみがえり） — 設計

初代バイオハザードのような「洋館サバイバルホラー」を、1本のゲームとして作る。

## 芯（調べて確かめたことから）
- **緊張と緩和**（三上真司氏「ゲームの本質は『緊張と緩和』」Yahoo!ニュース特集）
  → 危ない廊下と、音楽が変わるセーブ部屋。扉の向こうが分からない間。
- **1発では死なないゾンビ**（同上「バイオは1発撃ってもゾンビは死なない」）
  → 弾は足りない。撃つか、避けて走り抜けるか（リスクとリターン）。
- **洋館を歩き回る楽しさ**（三上氏：洋風建築が好きで、おしゃれな洋館を歩くこと自体を楽しみとして出したかった）
  → 明治の洋館。部屋ごとに違う手ざわり。調べれば必ず一言返ってくる。
- **倒せる怪物の爽快感**（スウィートホームの「逃げるだけ」への疑問から、倒せる要素を入れた）
- **音**（廊下の犬の場面は「音」の使い方が怖さの元／環境音で空間を作る：電ファミ）
- **見えない先**（固定カメラで曲がり角の先が見えない＝遊んだ人・記事の声。三上氏本人は技術の制約からの選択と語っていたので「芯」とは呼ばない）
- **操作の不満**（「ラジコン操作めんどくさい」が一番多い不満）→ 初期は「かんたん操作」（倒した方向に進む）。ラジコン操作は設定で選べる。

## 1本のゲームとしての流れ
タイトル → オープニング（前庭・雨・犬）→ 洋館1F → 2F → 1F東 → 温室（中ボス）→ 地下 → 研究所 → 最深部（ボス1）→ 自爆まで3分 → ヘリポート（ボス2）→ エンディング（2種）→ 成績 → タイトル
- 死ぬと「YOU DIED」→ 最後にセーブした所から／タイトルへ
- セーブはタイプライター＋インクリボン（数に限り）。セーブ部屋にはアイテムボックス（どの部屋のボックスも中身は共通）。

## 物語（オリジナル）
明治の洋館「鷲尾邸」。三代当主・鷲尾弦一郎男爵は、病で亡くした娘・小夜（さよ）を取り戻すため、神代製薬に館の地下を明け渡した。研究は「黄泉計画」。七十年後、館の地下で事故が起きる。
県警・第七特殊対応班の如月遼（主人公）と早瀬は、消息を絶った先発隊を探しに鷲尾山へ。犬に襲われ、館へ逃げ込む。
- 早瀬：最初に館の奥へ消える。研究所の隔離房で、噛まれて熱にうかされている。血清を作って打てば、生きる（よい結末）。言葉は少なく、行動で存在を示す。
- 春日：ヘリのパイロット。合図があれば戻ると言って空へ。

## 部屋（全26＋前庭）と順路
1. 玄関ホール → 食堂（止まった大時計）→ 1F西廊下（最初のゾンビ・先発隊三浦の遺体）→ 使用人部屋（セーブ1・1Fの地図）→ 厨房（オーブンの中の真鍮の歯車）→ 食堂の大時計に歯車 → 鷹の鍵（時計が鳴り、ホールに何かが来る）
2. 2F西廊下（窓）→ 子ども部屋（小さな鍵・小夜の絵日記＝名前）→ 寝室（鷹）→ 鏡台の引き出し（小さな鍵）→ 蛇の鍵（衣装棚からゾンビ）→ 2F西廊下の窓を破って犬
3. 2F回廊（蛇）→ 図書室（家系図・2Fの地図・押せる本棚の奥に狩猟用の鍵）→ 回廊の肖像画を生まれた順に → 狼の鍵
4. 1F東廊下 → 書斎（鷹）→ 銃の棚（狩猟用の鍵）→ ショットガン（東廊下にゾンビが来る）
5. 温室（狼）→ 庭師（中ボス）→ 地下室の鍵
6. 厨房 → 地下貯蔵庫（大蜘蛛・毒・青ハーブ・バルブハンドル）→ ボイラー室 → 管理人室（セーブ2）→ ボイラーのバルブを閉める → 地下通路 → 昇降機
7. 警備室（セーブ3・研究所の地図）→ 研究所廊下 → 研究室（試薬B・合成機）→ 培養室（狩人が割れて出る・IDカード・試薬A）→ 隔離房（ID・マグナム・早瀬）→［血清を作って早瀬に］→ 最深部（ID＋合言葉 SAYO）→ 救難信号 → ボス1 → 自爆3分 → 搬出路 → ヘリポート → ボス2（ヘリからグレネード）→ 脱出

## 完成の基準（これだけ作れば完成）
- 上の順路を、タイトルからエンディングまで、ボットが実際の操作ルール（当たり判定・鍵・敵）で通しきれる
- 全部の部屋・全部のカメラを写真で見て、おかしな所がない
- 死ぬ・続きから・セーブ/ロード・2つの結末・成績・タイトルに戻る、がすべて動く
- スマホ（横・縦）とPC（キーボード・ゲームパッド）で操作できる
