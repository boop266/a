# 街

ゾンビがはびこる街を、自転車で駆け抜けるだけのゲーム。`index.html` 一枚で動く（ブラウザで開くだけ）。

- 操作：画面左を触るとスティックが出る。倒し具合で 歩き → ダッシュ → 倒し切ると本気ダッシュ（スタミナを使う）。
- タップ：自転車・スケボーに乗る／降りる、家に入る／出る、冷蔵庫・食器棚・水道・自販機・水飲み場・畑の野菜で飲む／食べる。触れるものは近づくと小さく光る。
- 家の入口・出口へ歩いて押し込んでも出入りできる。
- キーボード：矢印 / WASD で歩き、Shift でダッシュ、X（または Z）で本気ダッシュ、Space / E でタップの代わり。
- 丘や高台がある。坂は乗り物の速さが変わり（登りは遅く、下りは速い）、高い所ほど遠くまで街が見える。
- 下の中央の細いバーがスタミナ、左下の2本が空腹（橙）と水分（青）。空腹か水分が尽きると終わる。
- `?seed=数字` で同じ街を何度でも出せる。
- 調整値はすべて `index.html` の `CFG`（ロジックの先頭）にまとまっている。
