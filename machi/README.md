# 街

ゾンビがはびこる街を、自転車で駆け抜けるだけのゲーム。`index.html` 一枚で動く（ブラウザで開くだけ）。

- 操作：画面左を触るとスティックが出る（奥まで倒すとダッシュ）。自転車の近くでタップすると乗る／もう一度タップで降りる。
- キーボード：矢印 / WASD で移動、Shift でダッシュ、Space / E で乗り降り。
- `?seed=数字` で同じ街を何度でも出せる。
- 調整値はすべて `index.html` の `CFG`（ロジックの先頭）にまとまっている。

## テスト

```sh
node tests/bot.js [シード数=50] [ターン数=2000] [最初のシード=1]
```
