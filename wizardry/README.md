# 深淵の迷宮

一人称の3Dダンジョンを、4人のパーティで潜るRPG。`index.html` 一枚で動きます（ブラウザで開くだけ）。

- 遊び方：W/A/S/D・矢印で移動、Q/Eで横歩き、Spaceでその場で待つ、Mで地図、Cでキャンプ。メニューは数字キーでも選べます。スマホは画面下のボタン（長押しで歩き続ける）か、迷宮の絵をスワイプ。
- 目的：B5の玉座にいる「深淵の王」を倒し、暁のアミュレットを地上へ持ち帰る。

## テスト

```sh
# 自動で最後まで遊ぶボット（バランス確認と、詰まり・エラー探し）
node wizardry/tests/bot.js [回数=3] [上限の手数=60000]
```

| 変数 | 意味 |
|---|---|
| `NEED='[0,1,2,3,5,7]'` | 各階へ下りるのに必要な平均レベル（小さくすると急いで潜る） |
| `BOT_OUT=dir` | 最後の画面のスクショの保存先（既定は一時フォルダ） |
| `V=1` | 途中経過を表示 |
