# ひとしずく　ことだま絵巻

名を忘れられたものは、絵巻から白く消えていく。
年老いた絵師の筆から、さいごの墨が**ひとしずく**こぼれた。
あなたはその一滴。字を書くと、字が本物になる絵巻の中を旅して、ものに名を返していく。

`index.html` を開くだけで遊べます（1 ファイル・外部への通信なし）。

## 遊び方

- **歩く**：絵巻をタップすると、そこへ歩く。
- **書く**：下の字帳から字を引っぱって絵巻に置くと、その字が本物になる（橋・一本の線・火・雨・竜……）。
- **合わせる**：字に字を重ねると新しい字が生まれる（木＋木＝林、日＋雨＝虹）。絵巻の中の物に重ねても合わさる。
- **思い出す**：薄れたものに正しい名を書くと、色がよみがえる。
- **墨**：書くと墨を使う。書いた字をタップすると墨がもどる。
- どの場面にも、解き方はいくつもある（「解き方の印」を集めてみてください）。

序の巻〜六の巻（野・川・山・里・夜・空）と終の巻、全 26 場面。
さいごに、旅してきた場面の写しをつないだ「あなたの絵巻」が流れます。

## 作り方・確かめ方

```sh
node tools/build.js          # src/ をまとめて index.html と .gen/artifact.html を作る（字体の切り出しあり）
node tools/build.js --fast   # 字体の作り直しを省く

# テスト（Playwright）
node tests/regress.js        # 世界の決まり（35 件）
node tests/solve.js          # 各場面を、ちがう解き方で最後まで（53 通り）
node tests/fuzz.js 220       # いたずらボット：でたらめに書く・歩く・合わせる
```

- `src/NN_*.js` を番号順につなげて 1 枚の HTML にします。
- 筆の動きは KanjiVG の中心線にそって、毛先のだ円を押していく自前の筆で描いています。
- 音（琴・尺八・太鼓・効果音・主題曲）は、すべてその場で WebAudio で鳴らしています。
